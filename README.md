## 🚀 How to Run & View

1. Simply double-click on `index.html` or right-click and choose **Open with > Chrome / Edge / Firefox / Safari**.
2. No build steps or package installations needed!

---

## 🛠️ How to Replace or Update Files

### 1. Update Your Resume PDF
1. Save your latest resume as `Priyanka_KV_Resume.pdf`.
2. Place it in the `assets/` folder.
3. The "Download Resume" buttons across the site will automatically download this file.

### 2. Update Profile Picture
1. Save your new photo as `profile-photo.jpg`.
2. Place it in the `assets/` folder to instantly update both Hero and About Me sections.

---

## 🌐 Deploying to GitHub Pages (Free)

1. Create a repository on GitHub (e.g. `p7337707-star.github.io` or `portfolio`).
2. Push these files to the `main` branch.
3. In your GitHub repository settings, go to **Pages** > Set Source to `main` branch > Click **Save**.
4. Your portfolio is live!
